# Data attribution

The generated city index in
`src/lib/job-import/city-data.generated.json` contains data from
[GeoNames](https://www.geonames.org/), licensed under the
[Creative Commons Attribution 4.0 License](https://creativecommons.org/licenses/by/4.0/).

Run `bun run cities:build` to refresh the checked-in index from the official
GeoNames `cities5000` extract.
